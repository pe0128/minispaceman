# minispaceman可交互桌宠

面向 **Windows 与 macOS** 的宇航员像素桌宠 App。

当前处于素材调研与需求准备阶段，尚未选定技术栈，也没有可运行程序。具体行为和开发目标待用户提供。

## 项目边界

- 本目录是项目根目录，项目所需代码、配置、文档及运行素材均应在本目录内。
- `assets/` 存放项目实际使用的素材。使用源素材前，必须先复制到这里，再通过项目内路径引用。
- 外部素材来源为 `D:/aseprite/spaceman/`，其 `README.md`、`INDEX.md`、`rig.json` 与各目录的清单描述素材结构和动画参数。
- 外部素材目录不是项目运行依赖，不可直接引用其中的图片，也不可依赖指向它的符号链接。

## 目录

| 路径 | 用途 |
| --- | --- |
| `assets/` | 后续按实际需要复制的图片、动画参数等运行素材 |
| `docs/asset-notes.md` | 已核对的动作、图层、绑定规则和实现注意事项 |
| `AGENTS.md` | 后续开发需遵循的项目约束 |

## 开发准备

后续需要结合行为需求确定透明桌面窗口、鼠标交互、屏幕边界、多显示器与高 DPI 的处理方式，并分别在 Windows、macOS 上验证。初步考虑将行为状态、动画播放和系统窗口适配分开，避免动画参数与平台逻辑耦合；这是准备思路，尚非技术方案。
