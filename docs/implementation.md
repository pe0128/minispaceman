# 实现说明

## 运行结构

Godot 主窗口不可隐藏，因此保留透明、穿透的 1px 宿主。可见桌宠与世界是两个独立原生子窗口；模式控制器统一管理普通、进入、游戏、暂停、退出和常驻停用。

宿主、普通桌宠与世界窗口在 Windows 上通过 WS_EX_TOOLWINDOW 隐藏任务栏按钮，设置使用 WS_EX_APPWINDOW。每次显示、重建窗口或改变桌宠窗口标志时重新应用策略。macOS 以 LSUIElement 启动，使用 AppKit 的 Accessory/Regular 激活策略随设置可见性切换 Dock 图标；后台模式仍允许世界窗口获得输入焦点。

进入时隐藏桌宠并等待合成帧，采集当前屏幕图像和外部窗口快照。桌面服务统一转换原生窗口坐标、截图像素和世界坐标；按从前到后的窗口矩形裁去遮挡，生成可见顶边单向平台。截图仅保留在当前会话内存中。

角色在两个窗口间共享屏幕锚点，不把锚点等同于窗口左上角。普通模式保存显示器索引、屏内位置与朝向到 `user://position.cfg`；显示器失效后回到有效范围。

世界使用 CharacterBody2D 角色、静态平台和三个 RigidBody2D 道具。飞行输入状态独立于动画：按下触发跳跃/空中启动，持续按住触发推力，松开切断推力；退出和失焦清空输入。

身体帧由运动状态决定，肩点和关节驱动枪口方向。副手使用独立肩点；持物时关闭道具物理，在副手与主手之间绘制，投掷第 4 帧恢复实体并赋速度。按逐帧 helmetSpans 处理头盔遮挡，按 gloveSamples 剔除手套亮点。

## 原生接口

`DesktopBridge.snapshot_windows()` 返回 `windows` 与 `displays`，记录包含矩形和本次快照标识；窗口保持从前到后的顺序。扩展只读取窗口元信息，不读取文字、不触发按钮、不注入系统输入。

Windows 排除本进程、最小化、隐藏、DWM cloaked、工具和桌面壳窗口，优先使用 DWM 可见边界。macOS 使用 CoreGraphics 读取屏幕普通层窗口与显示器边界，并检查/申请屏幕录制权限。Godot 本身负责图像捕获。

扩展使用本地引擎导出的 API JSON 与固定提交的 godot-cpp 构建。工具和 API 文件位于忽略目录，Windows 与 macOS 分别构建扩展。

## 实现边界

- 窗口按矩形近似，半透明、圆角、镂空和特殊系统浮层的遮挡可能不精确；受保护画面可能无法截图。
- 世界不跟随后台窗口变化，不暂停后台应用，也不操作真实界面。
- 游戏只在当前屏幕内运行；普通桌宠可以跨屏拖动。显示器拓扑变化时退出世界。
- macOS 权限、Spaces、混合 DPI 和透明窗口需要实机验收；CI 构建成功不能代替这些检查。
- 普通模式 30 FPS，游戏目标 60 FPS；停用且设置、托盘菜单均隐藏时降至 5 FPS，角色处理禁用。实际功耗与性能需要在目标设备测量。
- 开发构建使用临时签名；公开证书、商店发布、自动更新和公开 Release 不在本次实现范围内。

## 设置与扩展

`settings_store.gd` 集中维护默认值、校验、配置版本和 changed 信号。配置先写临时文件，再原子替换正式文件；失败保留草稿。版本 2 保留旧的 autostart 值与其他配置，将登录项注册从保存流程分离。位置存储与配置分离。

`settings_window.gd` 的 CATEGORIES 注册分类，独立页面继承 `settings_page.gd`。新增设置时，在 Store 的默认值和校验中加入字段，在对应页面绑定草稿，并在应用控制器响应 changed。整个窗口共享一份草稿，不因切页而丢失修改。`settings_theme.gd` 集中维护颜色、字体、交互状态和系统主题响应。

双击桌宠始终进入世界；已有设置窗口隐藏并停用处理，草稿保持在内存，返回后重新打开继续编辑。右键仅保留设置和退出。界面只显示标签、选项和操作按钮；授权、保存失败与未保存修改按需提示。

字体由 ui_fonts 统一创建，主字体 Times New Roman，中文字符回退至 SimSun/Songti SC。按钮、应用按钮和分类导航使用独立主题变体，显式覆盖 hover_pressed 等状态，所有状态保持相同内容边距。

尺寸采用素材倍率 1/2/3/4，对应 50/100/150/200%。普通窗口、透明命中区域、角色视觉、碰撞体、持物和道具共用倍率；脚下屏幕坐标在改变尺寸时保持不变，屏幕边缘会做可见范围校正。速度、重力、跳跃和喷气推力保持原值。

`jet_effect.gd` 从素材 manifest 读取三档效果：小号循环播放，中、大号按各自 interval/life/speed/spreadSpeed/maxScale/burst 发射独立气团。气团位置在出生时固定到全局坐标，角色移动不会带走已发出的烟雾；数量限制为 64。

正式应用首次运行注册当前用户登录项，并以 `resident_login.cfg` 保存已尝试的可执行文件位置；之后不自动重新启用用户在系统中禁用的项目。Windows 写入 HKCU Run，命令为加引号的路径和 `-- --startup`，并读取 StartupApproved 的禁用状态。macOS 通过 ServiceManagement 注册主应用，缓存启动 Apple event 的登录标记，并保留 Godot 原有 delegate，仅增加 Finder 重新打开处理。编辑器不注册。

「开机自启动」只控制登录启动后的角色启用状态；登录项和后台进程始终保留。手动启动始终启用角色，托盘启停不保存开机偏好。世界中停用先保存世界角色位置并退出，再隐藏桌宠。

Windows 命名互斥体、macOS 当前用户文件锁提供单实例保护。`resident_service.gd` 在 127.0.0.1 的动态端口监听，将端口和每次随机的 256 位令牌写入用户目录 `resident.json`。重复手动启动发送令牌并等待确认后退出；重复登录启动直接退出。连接数量、请求大小和超时均有限制，正常退出清理端点文件。

DisplayServer 托盘接口不绑定原生菜单，而是左右键点击后显示 Godot PopupMenu，以保持宋体和 Times New Roman。菜单包含当前启停操作、设置、退出，停用时图标灰化。应用及各原生窗口始终使用彩色宇航员图标，PNG/ICO/ICNS 由 `tools/generate_icons.gd` 从项目内站立第一帧生成。托盘不可用时打开设置并提示，关闭该设置会退出，避免失去操作入口。

## 构建检查

项目不再保留测试专用代码或输出。CI 使用 Godot 导入、原生 debug/release 编译及 Windows/macOS 导出检查。设置交互、登录项权限、显示器 DPI 与窗口行为仍应在目标系统验收。

SCons 的 compiledb 目标在项目根目录生成 clangd 数据库；tools/compilation_database.py 将真实命令转为 arguments 数组，解析绝对编译器路径，并把 MSVC 的 INCLUDE 环境写入参数。无需依赖编辑器继承 Visual Studio 环境，也不修改 godot-cpp 子模块。
